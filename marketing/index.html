Run your crew

One owner. Multiple techs. Permissions you control.

Add as many technicians as you need. Each one gets their own login, sees only what you let them see, and gets attributed on every job and invoice they touch.

1
Buy a tech seat
Settings → Team → Buy a Tech Seat. We bill it pro-rata for the rest of the current month — no surprise lump charges. Remove a seat later and you're credited pro-rata too.
2
Set permissions
Six toggles control what each tech can do — see all jobs vs only their own, create invoices, record payments, see clients, see the dashboard, and more. Different techs can have different permissions.
3
Hand them a Tech ID
We generate a unique Tech ID for each technician — short, easy to type, and tied to your account. They sign in with that ID and a password you set. No personal email required, no app store account, no extra paperwork. You hand it over and they're working.
